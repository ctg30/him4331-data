🚀 Start here (first time, about 5 minutes)

You will not write any Python in this course. Every notebook already has the code written. You do two things: press ▶ to run a cell, and type words between quotation marks in the 🟨 TODO cells.

What you need

A Google account (your school one is fine) and the Chrome or Edge browser. Notebooks open in Google Colab, which is free and runs in the browser. Nothing to install.

How every week works (same 5 steps, every module)

  1. Open this week's notebook from the module card below. It opens in Colab.
  2. Save your own copy: File → Save a copy in Drive. Rename it HIM4331_M03.4_LastnameFirstname (use that week's code). You cannot save into the original, so this step is required.
  3. Make sure you can see the code. Every cell shows its Python code by default. If you ever see only a cell title with no code under it, click Show code on that cell (or View → Show code / Edit → Show code in the menu). The code is already written; you only type inside the quotation marks on the 🟨 TODO lines.
  4. Run cells top to bottom. Step 1 (setup), Step 2 (your project card), Step 3 (load data), then this week's 🟨 TODO cells. Watch for green ✅. A yellow 🟨 message tells you exactly what to fix.
  5. Run the 📤 Submission Block at the bottom. It prints everything that gets graded in one box.
  6. Export the PDF and upload to that week's Canvas assignment. Steps here.

📎 Export a PDF and submit (every week)

  1. Scroll to the 📤 Submission Block and confirm it printed with no 🟨 warnings. If you see one, fix that TODO cell, re-run it, then re-run the submission block.
  2. In Colab: File → Print (or Ctrl+P on Windows, Cmd+P on Mac).
  3. In the print window, set Destination to Save as PDF. Leave everything else alone. Click Save.
  4. Name it HIM4331_M03.4_LastnameFirstname.pdf (use the current module's code).
  5. Open the matching Canvas assignment (for example M03.4 inside Module 3) and upload the PDF.
  6. Open the PDF once before you upload. If charts are cut off or text is missing, go back to Colab, run Runtime → Run all, wait for every cell to finish, and print again.

Tip: if Colab's Print gives you a blank page, scroll the notebook all the way to the bottom first so every output has rendered, then print.

🗂️ Dataset cheat sheet

Four datasets. Pick one in Module 2 and keep it all semester. Column names must be copied exactly (capitals, spaces, underscores).

diabetes (safety pick: works for every week)

What it is: about 100,000 diabetic inpatient encounters at 130 US hospitals, 1999 to 2008.

Number columns: time_in_hospital, num_medications, num_lab_procedures, num_procedures, number_diagnoses

Category columns: age, race, gender, readmitted, insulin, change, diabetesMed, medical_specialty

Watch out: missing values hide as "?" in weight, medical_specialty, payer_code, race. readmitted has three groups (NO, >30, <30); in Module 6 use COMPARE_GROUPS = ["<30", "NO"] if your question is about 30-day readmission.

hospitals

What it is: CMS Hospital General Information: one row per US hospital with ownership, type, and star rating.

Category columns: Hospital overall rating, Hospital Ownership, Hospital Type, Emergency Services, State

Number columns: Count of Facility MORT Measures, Count of READM Measures Worse

Watch out: Hospital overall rating is stored as text because ~1,000 hospitals say Not Available. In Module 4 choose fix to_number on it if your question uses the rating as a number.

readmissions

What it is: CMS Hospital Readmissions Reduction Program: six readmission measures per hospital with predicted, expected, and excess ratios.

Number columns: Excess Readmission Ratio, Number of Discharges, Predicted Readmission Rate, Expected Readmission Rate, Number of Readmissions

Category columns: Measure Name, State

Watch out: many rows are blank (CMS suppresses small hospitals). In Module 4 choose drop_rows on the column your question needs, and build the yes/no column MY_FLAG (column Excess Readmission Ratio, cutoff 1.0). You need MY_FLAG for Module 5.

breaches

What it is: HHS Office for Civil Rights breach portal: reported health data breaches affecting 500 or more people.

Number column: Individuals Affected

Category columns: Type of Breach, Covered Entity Type, Business Associate Present, Location of Breached Information, State

Watch out: 2 duplicate rows, and one breach affected 192.7 million people, which swamps every average. That is a real finding to write about, not a mistake.

🆘 Stuck?

🟨 Yellow "NOT DONE YET"

Not an error. The notebook is telling you what to fix in that one cell. Fix it, press ▶ again, watch it turn ✅.

🟥 Red error text

It can't hurt anything. You can't break the notebook or the data. Try Runtime → Run all, which re-runs everything in order. Nine times out of ten the cause is a cell above that hasn't been run yet.

"This cell needs an earlier cell finished first"

Exactly what it says: scroll up, finish the TODO cells above it in order (Step 2 before Step 3, and so on).

I only see a title, no code

Click Show code on that cell, or use Edit → Show code in the Colab menu. You need the code visible to type your answers.

Column name not found

Copy it exactly from the column list printed in the notebook, including capital letters and spaces. Hospital overall rating is not hospital_overall_rating.

Colab says the session disconnected

Normal after idle time. Click Reconnect, then Runtime → Run all. Your typed answers are still there.

Still stuck after 15 minutes?

Screenshot the cell and the message and send it to your instructor. That isn't cheating, that's the process.
